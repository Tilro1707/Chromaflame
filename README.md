# Chromaflame

A short 2D platformer where you play a flame. Switch between colours to change how you interact with the platforms and the level.

Made for [Mini Jam 218: Fire](https://itch.io/jam/mini-jam-218-fire) (limitation: 3 colours).

## Tech

- Unity 6000.3.8f1

Open the folder in Unity Hub with the matching editor version.
